# 每日新闻 Daily News - 饥荒联机版模组

## 📰 模组介绍

这是一个为《饥荒联机版》(Don't Starve Together) 制作的趣味模组。每天白天开始时，会在聊天框中播报新闻，每条新闻对应一个当天会发生的特殊游戏事件。

## ✨ 特性

- 🌅 每天白天自动播报新闻（可配置1-3条）
- 🎲 50种不同的特殊事件，每天随机组合
- 💬 新闻通过游戏聊天框显示
- 🎮 事件效果真实影响游戏玩法
- 🎭 两种播报风格：正式播报 / 调皮趣味

## ⚙️ 配置选项

### 1. 每日事件数量
- 1个事件（默认）
- 2个事件
- 3个事件

### 2. 新闻播报风格
- **正式播报**（默认）：严肃正经的新闻风格
  - 示例：【猪人节日】今天是猪人的盛大节日！所有猪人都非常友好，招募顺从度大幅提升！
- **调皮趣味**：轻松幽默的播报风格
  - 示例：【猪猪狂欢】哇哦！猪猪们今天心情超好，给根胡萝卜就能当你小弟啦~

## 🔧 安装方法

1. 下载模组文件
2. 将整个文件夹放入饥荒联机版的 mods 目录：
   - Windows: `文档/Klei/DoNotStarveTogether/mods/`
   - Mac: `~/Documents/Klei/DoNotStarveTogether/mods/`
   - Linux: `~/.klei/DoNotStarveTogether/mods/`
3. 启动游戏，在模组菜单中启用"每日新闻 (Daily News)"
4. 在模组配置中调整事件数量和播报风格
5. 创建或加入世界即可体验

## 🎮 使用说明

- 模组会在每天白天开始后约3秒自动播报新闻
- 新闻会在聊天框中显示，包含随机事件
- 事件效果会立即生效并持续整天
- 每天的事件都是随机的，增加游戏趣味性
- 可以在模组配置中调整事件数量（1-3个）和播报风格
- 修改配置后需要重启世界才能生效

## ⚙️ 技术说明

- 服务器端模组，需要服务器安装
- 兼容饥荒联机版最新版本
- 不需要客户端强制安装

## 📝 注意事项

- 此模组会改变游戏平衡性，建议与朋友一起游玩时使用
- 某些事件可能会让游戏变得更简单或更困难
- 如遇到问题，可以尝试重启服务器
- 修改配置后需要重启世界才能生效
