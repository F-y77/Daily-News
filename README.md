# 每日新闻 Daily News - 饥荒联机版模组

## 📰 模组介绍

这是一个为《饥荒联机版》(Don't Starve Together) 制作的趣味模组。每天白天开始时，会在聊天框中播报新闻，每条新闻对应一个当天会发生的特殊游戏事件。

## ✨ 特性

- 🌅 每天白天自动播报新闻（可配置1-3条）
- 🎲 30种不同的特殊事件，每天随机组合
- 💬 新闻通过游戏聊天框显示
- 🎮 事件效果真实影响游戏玩法
- 🎭 两种播报风格：正式播报 / 调皮趣味
- ✅ 所有事件都经过测试，确保有效

## ⚙️ 配置选项

### 1. 每日事件数量
- 1个事件（默认）
- 2个事件
- 3个事件

### 2. 新闻播报风格
- **正式播报**（默认）：严肃正经的新闻风格
  - 示例：【青蛙雨季】今天会有大量青蛙出现！
- **调皮趣味**：轻松幽默的播报风格
  - 示例：【呱呱来袭】青蛙大军从天而降，呱呱呱呱呱！

## 🔧 安装方法

1. 下载模组文件
2. 将整个文件夹放入饥荒联机版的 mods 目录：
   - Windows: `文档/Klei/DoNotStarveTogether/mods/`
   - Mac: `~/Documents/Klei/DoNotStarveTogether/mods/`
   - Linux: `~/.klei/DoNotStarveTogether/mods/`
3. 启动游戏，在模组菜单中启用"每日新闻 (Daily News)"
4. 在模组配置中调整事件数量和播报风格
5. 创建或加入世界即可体验

## 🎮 使用说明

- 模组会在每天白天开始后约3秒自动播报新闻
- 新闻会在聊天框中显示，包含随机事件               
- 事件效果会立即在玩家周围生成物品或生物
- 每天的事件都是随机的，增加游戏趣味性
- 可以在模组配置中调整事件数量（1-3个）和播报风格
- 修改配置后需要重启世界才能生效

## 🧪 测试方法

1. **启动游戏**并创建新世界
2. **等待白天**开始（或使用控制台命令 `c_skip()` 跳过时间）                   
3. **观察聊天框**，应该会看到新闻播报
4. **查看周围**，应该能看到生成的物品或生物
5. **验证效果**：
   - 如果是青蛙/蝴蝶/火鸡/企鹅，应该能看到生物在移动
   - 如果是花朵/燧石/树枝/草/浆果/胡萝卜，应该能在地上捡到

## ⚙️ 技术说明

- 使用 `GLOBAL.setmetatable` 方式访问全局变量
- 服务器端模组，需要服务器安装
- 兼容饥荒联机版最新版本
- 不需要客户端强制安装
- 所有事件使用 `SpawnPrefab` 生成，简单可靠

## 📝 注意事项

- 此模组会在玩家周围生成物品和生物
- 生成的生物可能会攻击玩家，请做好准备
- 如遇到问题，可以尝试重启服务器
- 修改配置后需要重启世界才能生效
- 建议配合朋友一起游玩，增加趣味性
