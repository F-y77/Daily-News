# 每日新闻 Daily News - 饥荒联机版模组

## 📰 模组介绍

这是一个为《饥荒联机版》(Don't Starve Together) 制作的趣味模组。每天白天开始时，会在聊天框中播报三条"新闻"，每条新闻对应一个当天会发生的特殊游戏事件。

## ✨ 特性

- 🌅 每天白天自动播报三条随机新闻
- 🎲 30种不同的特殊事件，每天随机组合
- 💬 新闻通过游戏聊天框显示
- 🎮 事件效果真实影响游戏玩法

## 📋 事件列表（30种）

1. **猪人节日** - 猪人友好度大幅提升
2. **兔人狂欢** - 兔人移动速度提升但更具攻击性
3. **蜘蛛迁徙** - 蜘蛛不主动攻击，巢穴生长加快

5. **蜜蜂罢工** - 蜂箱不产蜜但蜜蜂不攻击
6. **鸟类迁徙** - 捕鸟陷阱效率翻倍
7. **植物生长日** - 农作物生长速度+50%
8. **矿石丰收** - 开采矿石有概率双倍产出
9. **树木繁茂** - 砍树额外掉落树枝和松果
10. **猎犬休息日** - 猎犬不会来袭
11. **青蛙雨季** - 下雨时大量青蛙出现
12. **蘑菇繁殖** - 蘑菇采摘后立即重生
13. **幽灵活跃** - 幽灵掉落更多噩梦燃料
14. **食物保鲜** - 食物腐烂速度减半
15. **火焰节** - 火源燃烧时间延长
16. **冰冻之日** - 温度下降，冰箱效果提升
17. **鱼群聚集** - 钓鱼效率大幅提升
18. **蝴蝶漫舞** - 大量蝴蝶出现
19. **机械降临** - 发条生物掉落更多齿轮
20. **蜘蛛女王** - 更高概率遇到蜘蛛女王
21. **精神焕发** - 精神值恢复速度提升
22. **饥饿减缓** - 饥饿速度降低
23. **生命旺盛** - 生命恢复速度提升
24. **工具耐久** - 工具耐久消耗减半
25. **暗影之力** - 制作暗影物品不消耗精神
26. **Boss狂暴** - Boss更强但掉落翻倍

29. **魔法涌动** - 魔法物品消耗减少
30. **和平之日** - 所有生物不主动攻击

## 🔧 安装方法

1. 下载模组文件
2. 将整个文件夹放入饥荒联机版的 mods 目录：
   - Windows: `文档/Klei/DoNotStarveTogether/mods/`
   - Mac: `~/Documents/Klei/DoNotStarveTogether/mods/`
   - Linux: `~/.klei/DoNotStarveTogether/mods/`
3. 启动游戏，在模组菜单中启用"每日新闻 (Daily News)"
4. 创建或加入世界即可体验

## 🎮 使用说明

- 模组会在每天白天开始后约3秒自动播报新闻
- 新闻会在聊天框中显示，包含三条随机事件
- 事件效果会立即生效并持续整天
- 每天的事件都是随机的，增加游戏趣味性

## ⚙️ 技术说明

- 使用 `GLOBAL.setmetatable` 方式访问全局变量，无需 `global.` 前缀
- 服务器端模组，需要服务器安装
- 兼容饥荒联机版最新版本
- 不需要客户端强制安装

## 📝 注意事项

- 此模组会改变游戏平衡性，建议与朋友一起游玩时使用
- 某些事件可能会让游戏变得更简单或更困难
- 如遇到问题，可以尝试重启服务器
