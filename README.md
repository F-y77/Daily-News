# 每日新闻 Daily News - 饥荒联机版模组

## 📰 模组介绍

这是一个为《饥荒联机版》(Don't Starve Together) 制作的趣味模组。每天白天开始时，会在聊天框中播报新闻，每条新闻对应一个当天会发生的特殊游戏事件。

## ✨ 特性

- 🌅 每天白天自动播报新闻（可配置1-3条）
- 🎲 30种不同的特殊事件，每天随机组合
- 💬 新闻通过游戏聊天框显示
- 🎮 事件效果真实影响游戏玩法
- 🎭 两种播报风格：正式播报 / 调皮趣味
- ✅ 所有事件都经过测试，确保有效

## ⚙️ 配置选项

### 1. 每日事件数量
- 1个事件
- 2个事件
- 3个事件

### 2. 新闻播报风格
- **正式播报**（默认）：严肃正经的新闻风格
  - 示例：【青蛙雨季】今天会有大量青蛙出现！
- **调皮趣味**：轻松幽默的播报风格
  - 示例：【呱呱来袭】青蛙大军从天而降，呱呱呱呱呱！

## 🎮 使用说明

- 模组会在每天白天开始后约3秒自动播报新闻
- 新闻会在聊天框中显示，包含随机事件               
- 事件效果会立即在玩家周围生成物品或生物
- 每天的事件都是随机的，增加游戏趣味性
- 可以在模组配置中调整事件数量（1-3个）和播报风格
- 修改配置后需要重启世界才能生效
