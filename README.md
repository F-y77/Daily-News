# 每日新闻 Daily News

饥荒联机版模组，每天白天在聊天框播报新闻，生成对应的物品或生物。

## 特性

- 60种不同事件
- 两种播报风格（正式/调皮）
- 可配置每日事件数量（1-3个）

## 事件类型

- 生物类：青蛙、蝴蝶、火鸡、企鹅、蜜蜂、蜘蛛、兔子、鼹鼠、鱼人、猪人等
- 资源类：燧石、树枝、草、木头、石头、金块、木炭、硝石、芦苇等
- 食物类：浆果、胡萝卜、蜂蜜、肉、鸟蛋、冰块等
- 稀有类：曼德拉草、齿轮、宝石、活木、噩梦燃料等
- 特殊类：科学机器、炼金引擎、暗影操纵者、宝箱、闪电、陨石等

## 安装

将文件夹放入 `mods` 目录，在游戏中启用即可。

## 配置

- 每日事件数量：1-3个
- 播报风格：正式/调皮
